READING JOURNAL - ANDROID APP PROJECT

Upload EVERYTHING in this folder to a GitHub repository (keep the hidden .github folder).
Then open the Actions tab, run "Build APK", wait about 5 minutes, and download
the "reading-journal-apk" file. Unzip it and install app-debug.apk on your phone.

Files:
  www/index.html            the app
  www/manifest.json, icons  app details
  package.json              libraries (PDF viewer, file sharing, alarms)
  capacitor.config.json     app settings
  .github/workflows/android.yml   build instructions
